# Sanaa Henna Academy — Team NEXORA

Premium responsive educational academy website demo.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design, layouts and animations
- `script.js` — navigation, course filters/details, gallery lightbox and registration flow
- `images/` — three supplied henna photos, stored locally for GitHub Pages

## Run locally
Open `index.html` in a browser. No build tools or backend are required.

## Before publishing
1. In `script.js`, replace `WHATSAPP_NUMBER = "212600000000"` with the real academy number in international format (digits only).
2. Replace the demonstration course descriptions/modules with approved real course information.
3. Replace the demo testimonials with verified student feedback, or remove that section.
4. Three photos supplied in this conversation are included in `images/` and linked locally. You can replace them with academy-owned images while keeping the same filenames.
5. Connect the registration form to a secure backend if submissions should be stored. In this demo, the form validates locally and opens WhatsApp with a prefilled message; it does not store or transmit data itself.

All course information and testimonials are explicitly marked as demonstration content. No certifications or credentials are claimed.
